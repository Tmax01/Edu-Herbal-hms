# EduHMS (Edu Herbal Clinic) — Enterprise Hospital Management System

A dual-paradigm (allopathic & herbal) clinical and administrative Hospital Management System built with **React / TypeScript / Vite** on the frontend and **NestJS / Prisma ORM / PostgreSQL** on the backend.

---

## 🚀 Live Deployments

- **Frontend Application (Vercel):** [https://edu-herbal-hms.vercel.app](https://edu-herbal-hms.vercel.app)
- **Backend API (Render):** [https://eduhms-backend.onrender.com](https://eduhms-backend.onrender.com)
- **API Swagger Docs:** [https://eduhms-backend.onrender.com/api/docs](https://eduhms-backend.onrender.com/api/docs)
- **Database:** Serverless PostgreSQL on [Neon.tech](https://neon.tech)
- **GitHub Repository:** [https://github.com/Tmax01/Edu-Herbal-hms](https://github.com/Tmax01/Edu-Herbal-hms)
