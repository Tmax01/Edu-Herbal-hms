 

 0. Global Shell (present on every screen after login)

- **Login screen** — single shared URL for both branches; email/username + password; "Forgot password" link
- **Top/side navigation** — module icons scoped to the logged-in user's role (a Pharmacist doesn't see Admission; a Receptionist doesn't see Production)
- **Branch indicator + switcher** — shows current branch context (e.g., "Accra"); Admin/Manager roles can switch to "All Branches" or the other branch; other roles are locked to their home branch
- **Global patient search bar** — searchable by name, MRN, or phone from anywhere in the app, returns the patient profile regardless of which branch registered them
- **Notification bell** — low-stock alerts, follow-ups due, pending lab results, etc., role-filtered

 3–4. Consultation (EMR + Herbal)

| Screen | Purpose | Key Elements | Leads To |
|---|---|---|---|
| **Active Visit Screen** | Doctor/consultant's main working screen | Patient summary panel (allergies flagged prominently), tabs: Conventional Notes / Herbal Notes, vitals entry, past-visit timeline sidebar | Prescription, Lab Order, Herbal Formulation |
| **Conventional Consultation Form** | Standard EMR entry | Chief complaint, diagnosis, vitals, notes, attach reports/scans | Prescription Form, Lab Order Form |

| **Prescription Form** | Create prescription (either type) | Product search (drug or herbal catalog), dosage, frequency, duration | Sends to Pharmacy queue |
| **Lab Order Form** | Request test(s) | Test type multi-select, notes | Sends to Lab queue |
